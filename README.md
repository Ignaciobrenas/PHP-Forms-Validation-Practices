## Descripción del Proyecto

Colección de ejercicios prácticos en **PHP** centrados en la captura, validación, saneamiento y procesamiento seguro de peticiones HTTP mediante métodos `$_GET` y `$_POST`.

---

## 📄 Relación de Ejercicios

| Archivo | Contenido y Objetivos |
| :--- | :--- |
| **`Ejercicio1.php`** | Formulario básico de captura de datos con métodos GET y POST. |
| **`Ejercicio2.php`** | Conversor de divisas y cálculo numérico a partir de datos de formulario. |
| **`Ejercicio3.php`** | Validación de campos obligatorios, cadenas vacías y tipos numéricos. |
| **`Ejercicio4.php`** | Procesamiento de controles avanzados: `<select>`, `radio buttons` y `checkboxes` múltiples. |
| **`Ejercicio5.php`** | Formulario de autenticación con verificación de credenciales de usuario. |
| **`Ejercicio6.php`** | Formulario persistente (*sticky form*) que mantiene los valores tras errores de validación. |
| **`Ejercicio7.php`** | Formulario integral con saneamiento contra ataques XSS mediante `htmlspecialchars()` y filtros de expresión regular. |

---

## 🚀 Ejecución Local

Para probar los formularios en tu navegador:

```bash
# Iniciar el servidor web embebido de PHP en la carpeta del proyecto

# http://localhost:8000/Ejercicio1.php
```
